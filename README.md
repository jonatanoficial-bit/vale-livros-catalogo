# Vale Livros — Catálogo de Livros Físicos

Catálogo editorial online de Jonatan Vale, atualizado em novembro de 2026.

- [Abrir catálogo (quando GitHub Pages estiver habilitado)](https://jonatanoficial-bit.github.io/vale-livros-catalogo/)
- **index.html**: vitrine interativa com 20 livros físicos, imagens, filtros e links de compra.

## Publicação pelo GitHub Pages

No repositório, abra **Settings → Pages → Build and deployment**. Escolha **Deploy from a branch**, **main** e **/(root)** e clique em **Save**.

> Algumas imagens são artes ilustrativas devidamente sinalizadas. Confirme a disponibilidade na página da loja.
