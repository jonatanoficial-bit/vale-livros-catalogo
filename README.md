# Vale Livros — Catálogo de Livros Físicos

Vitrine comercial de **Jonatan Vale**, revisada em **18 de novembro de 2026**.

- **26 obras** no catálogo online e no PDF comercial; **25 páginas de compra física Hotmart** identificadas.
- Compra física exclusivamente pela **Hotmart**, com produção/impressão sob demanda pela **UICLAP** quando indicada.
- O catálogo online preserva capas disponíveis; artes alternativas estão sinalizadas como ilustrativas.
- O botão **IMPRIMIR / SALVAR PDF** abre a impressão do navegador para gerar uma cópia atual da vitrine.
- Publicação estática no `index.html`, com busca por título/assunto e filtros por categoria.
